# ТЗ — AutoParts Intelligence (lead brief)

## Цель
Полноценный **сервис поиска запчастей** для рынков **UA · MD · RO**, а не лендинг и не «демо ради демо».

## Рынки (только эти)
| Страна | Источники |
|--------|-----------|
| UA | `olx_ua`, `prom_ua`, `flagma_ua` |
| MD | `nine99_md` |
| RO | `olx_ro` |

Всё остальное (PL/BG/PT/Bazar/Балтика и т.д.) — **вне продукта**, убрать из default search и UI.

## Продуктовые требования
1. **Vehicle Search** — главный экран (sidebar + форма + лента + правая панель), как макет.
2. Запрос собирается из Make/Model/Generation/Year/Part/OEM.
3. Параллельный live-поиск по активным источникам (GraphQL / JSON-LD), без CAPTCHA-bypass.
4. Карточка оффера: фото, title, цена, источник, страна, ссылка View.
5. **Свежесть:** не показывать объявления старше **30 дней**, если дата известна. Без даты — помечать `unknown date`, по умолчанию **скрывать** (строгий режим свежести).
6. Сортировка: cheaper first (известная цена), без цены — в конец.
7. Честные бейджи: title-heuristic ≠ VERIFIED_EXACT. Не врать про fitment.

## Не делаем сейчас
- Fitment engine с OEM-доказательствами end-to-end в UI
- Seller ratings / landed cost FX (пока «shipping unknown»)
- Источники с ключами/CF

## Критерий готовности
- UI = рабочий сервис поиска, рынки только UA/MD/RO
- Live search возвращает свежие офферы
- Задеплоено на Vercel + запушено в GitHub
