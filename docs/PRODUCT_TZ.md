# ТЗ — AutoParts Intelligence (lead brief)

См. также **`docs/PRODUCT_TZ_V2.md`** (полный сервис + карта путей).

## Цель
Полноценный **сервис поиска запчастей** по всем источникам, которые отдают публичный каталог без обхода защит. Для закрытых — зафиксировать легитимный путь сбора.

## Рынки и источники (zero-key)
| Страна | Источники |
|--------|-----------|
| UA | `olx_ua`, `prom_ua`, `flagma_ua` |
| MD | `nine99_md`, `prom_md` |
| RO | `olx_ro` |
| PL | `olx_pl` |
| BG | `olx_bg`, `bazar_bg` |
| PT | `olx_pt` |

Закрытые (Allegro, eBay, Rozetka, AUTODOC, …) — **не обходим**; пути в `docs/ACCESS_PATHS.md`.

## Продуктовые требования
1. **Vehicle Search** — главный экран (sidebar + форма + лента + правая панель).
2. Запрос из Make/Model/Generation/Year/Part/OEM.
3. Параллельный live-поиск по активным источникам (GraphQL / JSON-LD).
4. Карточка: фото, title, цена, источник, страна, ссылка View.
5. **Свежесть:** не показывать объявления старше **30 дней**, если дата известна.
6. Сортировка: cheaper first; без цены — в конец.
7. Честные бейджи: title-heuristic ≠ VERIFIED_EXACT.

## Критерий готовности
- UI = рабочий сервис поиска по всем zero-key источникам
- `docs/ACCESS_PATHS.md` заполнен
- Live search возвращает свежие офферы
- Задеплоено на Vercel + запушено в GitHub
