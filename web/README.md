# AutoParts Core — website

Next.js сайт (не Streamlit). Деплой на Vercel из папки `web/`.

## Local

```bash
cd web
npm install
npm run dev
```

Откройте http://localhost:3000

## Vercel

Root Directory: `web`  
Framework: Next.js  
Region: `fra1`
